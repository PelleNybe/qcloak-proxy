# Security Policy — `qcloak-proxy`

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in `qcloak-proxy` (such as key-leakage in outbound payloads, permutation bias, or authentication bypass), please **do not** open a public GitHub issue.

Instead, report it responsibly to **Corax CoLAB**:
- **Email:** `security@coraxcolab.com`
- **Maintainer:** Pelle Nyberg (`@PelleNybe`)

We will acknowledge receipt within 48 hours and provide a coordinated disclosure timeline.
